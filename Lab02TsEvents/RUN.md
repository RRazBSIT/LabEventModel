# Laboratory Activity 2: TypeScript Events

## Description

This laboratory demonstrates typed event payloads, discriminated unions, type narrowing, generic handlers, and asynchronous event handling using TypeScript.

## How to Run

Install dependencies:

npm install

Compile the TypeScript files:

npx tsc

Run the compiled program:

node dist/main.js
